# Fixtures

Captured source bytes, so every parser is tested offline against what its source really
served. `manifest.json` records when each file was fetched and how it was trimmed;
`sources.yaml` names each source's URL and its `rights` verdict.

These files are third-party material. Each one belongs to its publisher, and the
repository's MIT license does not cover it. They are here only as test inputs.

If you publish one of these and want it removed, email contact@frontierterm.com with the
file's path. It comes out in the next commit.
